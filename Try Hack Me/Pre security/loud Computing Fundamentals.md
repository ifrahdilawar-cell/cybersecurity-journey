## What I Learned

- Cloud computing provides computing resources over the internet.
- Cloud environments can be deployed in different ways.
- Cloud services are offered through different service models.
- Cloud platforms allow users to create, manage, and scale resources on demand.

---

## Key Concepts

### Public Cloud

- Cloud services provided over the internet.
- Shared infrastructure managed by a cloud provider.
- Accessible to many customers.

Examples:
- AWS
- Microsoft Azure
- Google Cloud

---

### Private Cloud

- Cloud environment dedicated to a single organization.
- Greater control and customization.
- Often used for sensitive workloads.

---

### Hybrid Cloud

- Combines public and private cloud environments.
- Allows workloads to move between both environments.
- Provides flexibility and scalability.

---

### Infrastructure as a Service (IaaS)

- Provides virtualized computing resources.
- Users manage operating systems and applications.
- Cloud provider manages the underlying hardware.

Examples:
- Virtual Machines
- Storage
- Networking

---

### Platform as a Service (PaaS)

- Provides a platform for building and deploying applications.
- Users focus on development.
- Infrastructure is managed by the provider.

Examples:
- Web application hosting
- Development platforms

---

### Software as a Service (SaaS)

- Ready-to-use software delivered over the internet.
- No infrastructure management required.
- Accessed through a web browser.

Examples:
- Gmail
- Microsoft 365
- Google Docs

## Takeaway

Cloud computing allows organizations to access computing resources without owning physical infrastructure. Different deployment models (Public, Private, Hybrid) and service models (IaaS, PaaS, SaaS) provide flexibility based on business needs.
