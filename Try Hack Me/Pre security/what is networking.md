## What I Learned

- A network is a group of connected devices that can communicate and share data.
- The Internet is a global system of interconnected networks.
- Devices in a network are identified using IP addresses and MAC addresses.
- ICMP is used for network diagnostics and error reporting.
- The `ping` command uses ICMP to test connectivity between devices.

## Key Concepts

### Network
A network is a set of connected devices that can communicate and share resources.

### Internet
The Internet is a worldwide system of interconnected networks that allows global communication.

### IP Address
A logical address used to identify a device on a network.

Example:
192.168.1.1

### MAC Address
A unique physical address assigned to a device’s network interface card (NIC).

Example:
00:1A:2B:3C:4D:5E

### ICMP
Internet Control Message Protocol used for checking connectivity and sending error messages.

### Ping
A tool used to test whether a device is reachable over a network.

Example:
ping google.com
