## What I Learned

* A computer is made up of different hardware components that work together.
* Each component has a specific function.
* Computers use input and output devices to interact with users.
* Several steps occur before the operating system loads.

---

## Key Concepts

### Motherboard

* Connects all computer components together.
* Allows components to communicate.

**Analogy:** Skeleton and nerves.

---

### RAM

* Stores data currently being used.
* Fast but temporary storage.

**Analogy:** Short-term memory.

---

### CPU

* Executes instructions.
* Performs calculations and processing.

**Analogy:** Brain.

---

### GPU

* Processes graphics and visual data.
* Sends images to the monitor.

**Analogy:** Visual cortex.

---

### HDD / SSD

* Stores files and programs permanently.
* SSDs are faster than HDDs.

**Analogy:** Long-term memory.

---

### PSU

* Supplies power to all components.
* Essential for system operation.

**Analogy:** Heart and lungs.

---

### Network Adapter

* Allows communication with other devices and networks.
* Enables internet connectivity.

**Analogy:** Vocal cords.

---

### Input and Output

#### Input Devices

Used to send data to the computer.

Examples:

* Keyboard
* Mouse
* Microphone

#### Output Devices

Used to receive information from the computer.

Examples:

* Monitor
* Speakers
* Printer

---

## Computer Startup Process

### Step 1: Press the Power Button

* Powers on the system.

### Step 2: Firmware Starts

* BIOS/UEFI begins running.

### Step 3: Power-On Self-Test (POST)

* Checks hardware is working correctly.

### Step 4: Select Boot Device

* Finds a device containing an operating system.

### Step 5: Initiate Bootloader

* Loads the operating system.
