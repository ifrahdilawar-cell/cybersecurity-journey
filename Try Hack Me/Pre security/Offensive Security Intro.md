## What I Learned

- Offensive security is the practice of actively trying to find and exploit vulnerabilities in systems.
- It is done in a legal and controlled way to improve system security.
- Offensive security is also known as ethical hacking when performed with permission.

- The goal is to identify weaknesses before attackers do.

## Key Concepts

### Offensive Security
A security approach focused on attacking systems (with permission) to discover vulnerabilities.

### Ethical Hacking
Legally breaking into systems to test and improve security defenses.

### Security Mindset
Thinking like an attacker helps in understanding how systems can be exploited and how to defend them.

## Phases of Ethical Hacking

### 1. Reconnaissance
Collecting information about the target (domains, IPs, services, technologies).

### 2. Scanning
Identifying open ports, services, and possible vulnerabilities.

### 3. Gaining Access (Exploitation)
Using vulnerabilities to gain entry into a system.

### 4. Maintaining Access
Keeping access for further testing (used in real penetration testing scenarios).

### 5. Covering Tracks
Removing traces of activity (conceptual understanding only in labs).

## Takeaway

Offensive security is not about hacking randomly—it is a structured process used by professionals to improve system security and prevent real-world attacks.
