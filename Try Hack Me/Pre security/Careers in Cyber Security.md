## What I Learned

- Cybersecurity is a broad field with multiple career paths.
- Each role focuses on a different area such as defense, building secure systems, or attacking systems ethically.
- Choosing a path depends on interests like analysis, engineering, or offensive security.

---

## Security Analyst

### Overview
A Security Analyst focuses on monitoring systems and detecting threats.

### Responsibilities
- Monitor security alerts and logs
- Investigate suspicious activity
- Respond to incidents
- Help prevent cyber attacks

### Key Skills
- Networking basics
- Log analysis
- SIEM tools (e.g., Splunk, ELK)
- Understanding of attacks and malware

### Goal
To detect and respond to security threats in real time.

---

## Security Engineer

### Overview
A Security Engineer designs and builds secure systems.

### Responsibilities
- Implement security controls in systems and networks
- Configure firewalls, IDS/IPS, and security tools
- Improve system architecture security
- Automate security processes

### Key Skills
- Networking and system administration
- Cloud security basics
- Scripting (Python, Bash)
- Infrastructure security design

### Goal
To build strong and secure systems that are resistant to attacks.

---

## Penetration Tester

### Overview
A Penetration Tester (Ethical Hacker) simulates real attacks to find vulnerabilities.

### Responsibilities
- Test systems for security weaknesses
- Exploit vulnerabilities in a controlled environment
- Perform web, network, and application testing
- Write detailed security reports

### Key Skills
- Networking and Linux
- Web application security (OWASP Top 10)
- Tools like Burp Suite, Nmap, Metasploit
- Exploitation techniques

### Goal
To find and report security weaknesses before attackers exploit them.
