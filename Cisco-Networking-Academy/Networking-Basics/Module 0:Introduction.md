## What is Packet Tracer?

A network simulator for practicing without real equipment. It can simulate home, office, IoT, and enterprise networks, in **logical** or **physical** view.

* * *

## Configuring Devices

- **Config Tab** – GUI setup (PT-specific), shows the equivalent CLI commands
- **CLI** – command-line setup like real Cisco devices
- **Desktop Tab** (end devices) – IP config, wireless, command prompt, web browser
- **Services Tab** (servers) – HTTP, DHCP, DNS

* * *

## Packet Tracer File Types

| File | Purpose |
|------|---------|
| `.pka` | Scored activity with instructions (initial + answer network) |
| `.pkt` | My own saved network, no scoring |
| `.pksz` | Activity bundled with hints |
| `.pkz` | Obsolete |

**PTMO** and **PTSA** are used for assessments.

* * *

## Activities

- PTTA – Logical and Physical Mode Exploration
- Packet Tracer – Create a Simple Network (build, configure end devices, verify connectivity)

* * *

## Key Takeaways

- Packet Tracer = safe, equipment-free practice
- Config Tab teaches the matching CLI commands
- `.pka` = activity, `.pkt` = my own network
